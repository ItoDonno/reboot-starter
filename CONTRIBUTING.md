# Contributing

Thanks for helping improve Reboot Starter.

## Quick Start

1. Fork and clone the repo.
2. Install dependencies: `npm install`
3. Run tests: `npm test`

## Development Notes

- The CLI entry point is `cli.js`.
- Tasks are stored in `~/.reboot-starter/tasks.json`.
- Prefer small, focused changes with matching tests.

## Pull Requests

- Describe the problem and the solution.
- Include tests for new behavior.
- Keep CLI output consistent with existing commands.

## Reporting Issues

Please include:

- Your OS and Node version
- The command you ran
- The exact output or error
